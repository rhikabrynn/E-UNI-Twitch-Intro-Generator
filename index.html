How to use the overlay:

01  Enter your pilot name and customise the subtitle, quote and badges.


02  The quote field is optional — leave it blank and it won't appear.


03  Click GENERATE PREVIEW to see the result. The checkerboard background represents transparency.


04  Click DOWNLOAD to save the HTML file.


05  In OBS, add a Browser Source with the downloaded file. Set resolution to 1920×1080 and enable Shutdown source when not visible.


06  Make sure Allow transparency is checked in the Browser Source settings.
